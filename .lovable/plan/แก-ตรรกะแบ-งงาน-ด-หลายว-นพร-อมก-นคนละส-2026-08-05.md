# แก้ตรรกะแบ่งงาน + ดูหลายวันพร้อมกันคนละสี

## 1. ทำไมงานแต่ละวันไม่สมดุล (ยืนยันจากโค้ดแล้ว)

มีสองจุดที่ทำให้เกิดภาพ "วันที่ 1 = 282 ป้าย / วันที่ 15 = 16 ป้าย" และ "คนที่ 1 = 1,235 ป้าย / คนที่ 2 = 22 ป้าย"

1. **การแบ่งวัน** (`splitIntoDays` → `balancedKMeans`) มีรอบปรับสมดุลจำกัดแค่ 12 รอบ เมื่อป้าย 1,235 จุดหาร 15 วัน ต้องย้ายจุดหลายร้อยครั้ง รอบปรับจึงหยุดกลางทาง → เหลือวันใหญ่มากและวันเล็กมาก
2. **การแบ่งคน แบบ "ล็อกจังหวัด"** แจกพนักงานตามสัดส่วนด้วยสูตรที่บังคับให้กลุ่มที่เหลือได้อย่างน้อย 1 คนก่อน ทำให้กลุ่มใหญ่ (กรุงเทพฯ ปริมณฑล) ได้พนักงานแค่ 1 คน ส่วนจังหวัดที่มี 2 ป้ายก็ได้ 1 คนเท่ากัน

## 2. สิ่งที่จะแก้

### สมดุลตามภาระงานจริง ไม่ใช่จำนวนป้าย
- แบ่งวันใหม่ด้วยการจัดกลุ่มเชิงพื้นที่ + รอบปรับสมดุลที่วนจนสมดุลจริง (ไม่จำกัด 12 รอบ) โดยเป้าหมายคือ **ชั่วโมงงานต่อวันเท่ากัน** = เวลาตรวจ (นาที/ป้าย ตามประเภทสื่อ) + เวลาขับประมาณ ไม่ใช่จำนวนป้ายดิบ
- เกณฑ์ยอมรับ: ทุกวันของคนเดียวกันต่างกันไม่เกิน ~15% ของค่าเฉลี่ย และไม่มีวันที่เหลือ 1-2 ป้ายขณะที่วันอื่นเป็นร้อย
- ถ้าจำนวนวัน × เพดานชั่วโมง ไม่พอกับงานทั้งหมด จะเตือนตรง ๆ ว่า "ต้องเพิ่มคน X คน หรือเพิ่มวัน Y วัน" แทนที่จะยัดทุกอย่างลงวันแรก

### แจกพนักงานตามปริมาณงาน
- โหมดล็อกจังหวัด: แจกพนักงานด้วยวิธีสัดส่วนเศษเหลือมากสุด (largest remainder) จังหวัดที่มีป้ายมากได้คนมากตามจริง จังหวัดเล็กรวมกลุ่มกันได้เมื่อพนักงานไม่พอ
- โหมดปกติ: คงการจัดโซนแบบเดิมแต่ให้เป้าหมายสมดุลเป็นชั่วโมงงานเช่นกัน

### ผลลัพธ์ที่แสดง
- การ์ดแต่ละวันแสดง ชม.งาน พร้อมแถบเทียบกับเพดาน และไฮไลต์วันที่เกิน
- สรุปเพิ่มบรรทัด "ความต่างของภาระงานระหว่างวัน" เพื่อให้ตรวจสอบได้ว่าสมดุลแล้ว

## 3. เลือกดูหลายวัน / ทุกวัน คนละสี

- เปลี่ยนการเลือกวันเป็น **multi-select**: กดการ์ดวันเพื่อสลับเปิด/ปิด, มีปุ่ม "ทุกวัน" และ "ล้าง" ต่อพนักงานหนึ่งคน
- เลือกข้ามพนักงานได้ เพื่อเทียบว่าคนไหนวิ่งโซนไหนและทับกันไหม
- แผนที่วาดหลายเส้นพร้อมกัน สีต่างกัน:
  - เลือกหลายวันของคนเดียว → ไล่เฉดสีของคนคนนั้น (วันที่ 1 เข้มสุด → วันท้ายอ่อนสุด)
  - เลือกข้ามคน → ใช้สีประจำตัวพนักงานแต่ละคน
- มีคำอธิบายสี (legend) บนมุมแผนที่: คนที่ N · วันที่ D · ระยะ · เวลา และกดที่ legend เพื่อซ่อน/แสดงเส้นนั้น
- หมุดป้ายบนแผนที่แสดงเฉพาะวันที่ถูกเลือก และใช้สีเดียวกับเส้น
- คำนวณเส้นทางจริง: ยิง OSRM ทีละวันแบบต่อคิว (สูงสุด 6 วันพร้อมกัน แล้วแจ้งให้เลือกน้อยลงถ้าเกิน) และ cache ต่อวันเหมือนเดิม จึงไม่เพิ่มภาระเซิร์ฟเวอร์ฟรีและไม่ใช้เครดิต AI
- ตารางลำดับหยุด: เมื่อเลือกหลายวันจะจัดกลุ่มตามหัวข้อ "คนที่ N · วันที่ D" (ยุบ/ขยายได้), Export CSV/GPX/KML รองรับหลายวันที่เลือก

## 4. รายละเอียดทางเทคนิค

- `src/lib/route-planner.ts`: เพิ่มฟังก์ชันแบ่งกลุ่มถ่วงน้ำหนัก (รับ weight ต่อจุด) + รอบปรับสมดุลแบบวนจนลู่เข้า, ใช้แทน `splitIntoDays` และแก้สูตรแจกพนักงานต่อจังหวัด
- `src/routes/route-monitoring.tsx`: state จาก `selected: {i,d}` → `selectedDays: Set<"i:d">`, คำนวณ route หลายวัน (`routes` cache เดิมใช้ต่อได้), legend, export ตามชุดที่เลือก
- `src/components/asset-map.tsx`: เพิ่ม prop `roadPolylines?: { points: LatLng[]; color: string; label?: string }[]` วาดหลายเส้น (คง `roadPolyline` เดิมไว้เพื่อไม่กระทบหน้า Asset Map)
- ทั้งหมดเป็นการคำนวณฝั่งไคลเอนต์ + OSRM ฟรี ไม่มีการเรียก AI
